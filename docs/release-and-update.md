# Сборка и обновления Trisko connect

Репозиторий: https://github.com/S-Hov/Trisko-connect

Продукт и пакет обновлений независимы от Geksa-A Connection:

- приложение: `Trisko.Connect.exe`;
- пакет Velopack: `TriskoConnect-Desktop`;
- установщик: `TriskoConnect-Setup.exe`;
- настройки: `%LocalAppData%\Trisko connect`;
- канал: `stable`, GitHub Releases этого репозитория.

Сборка первого пакета:

```powershell
.\scripts\build-release.ps1 -Version 0.1.0 -SkipPreviousReleaseDownload
```

Скрипт проверяет тесты, публикует самостоятельное приложение Windows x64, добавляет закреплённые VPN-ядра и лицензии, формирует установщик, portable-архив, архив исходников и контрольные суммы. Исходники должны быть закоммичены. `-AllowDirtySourceArchive` разрешает локальную проверку незакоммиченных изменений; такой пакет отмечается как тестовый.

Результаты: `artifacts/releases/<версия>`. Скрипт ничего не загружает в GitHub. Перед публикацией проверьте установленную сборку на отдельной Windows-машине с правами администратора и реальными VPN/удалёнными ресурсами.

Для следующей версии создайте `docs/releases/<версия>.md` и соберите новый пакет. Для дельта-обновлений укажите `-PreviousReleaseDirectory` либо используйте предыдущий релиз этого репозитория. Прежний корпоративный канал обновлений не используется.

## Разработка интерфейса

В Debug-сборке аргумент `--ui-preview` позволяет открыть оболочку без повышения прав, только если явно задан отдельный `TRISKO_CONNECT_DATA_DIRECTORY`. В Release-сборке исключения нет. TUN требует администратора.

## Переводы

Строки продукта: `ServiceLib/Geksa` и `ServiceLib/Resx/Trisko.en.json`. Подписи XAML используют свойства `TriskoStrings`. Новые сообщения обращаются к `TriskoLocalization.Text` или `Format`; подстановки должны сохранять номера и форматы. Выбранный язык применяется при старте, включая фоновые задачи и диагностику.

`eng/Localization` переносит литералы в вызовы локализации, `eng/localize-xaml.py` извлекает подписи XAML. Переводы добавляются в словарь и проверяются основным набором тестов.
