# Рабочая сеть SoftEther в Trisko Connect

1. На каждом Windows-ПК откройте **Удалённые рабочие столы → VNC → Настройки → Рабочая сеть SoftEther**. Если клиент SoftEther отсутствует, кнопка **Установить SoftEther** откроет мастер из Windows-комплекта Trisko. В мастере выберите **SoftEther VPN Client**.
2. Введите адрес и порт SoftEther, имя виртуального хаба и имя пользователя. На всех компьютерах укажите одну и ту же свободную частную подсеть, например `10.77.0.0/16`. Для каждого компьютера Trisko сама назначит IP-адрес на своём адаптере без шлюза по умолчанию.
3. Сохраните настройки. Если VPN уже подключён, переподключите его после смены адреса, порта или подсети. Введите пароль SoftEther и нажмите **Подключить рабочую сеть**. После первой настройки можно включить автоподключение рабочей сети вместе с основным VPN.
4. На принимающих компьютерах включите **Доступ к этому компьютеру** в настройках VNC. Задайте отдельный пароль VNC и нажмите **Подставить подсеть SoftEther**, чтобы ограничить входящий доступ этой подсетью.
5. Выберите компьютер из списка доступных рабочих мест или введите его девятизначный номер. Trisko запоминает номер и может сохранять пароль VNC в диспетчере учётных данных Windows по вашему выбору.

Участники должны быть в одном виртуальном хабе, где разрешён обмен трафиком между клиентами. Trisko объявляет имя компьютера, номер и порт VNC внутри рабочей сети. Для обнаружения приложение должно работать на принимающем компьютере. Если групповые пакеты не доставляются, Trisko запрашивает известные адреса и соседей виртуального адаптера. Подключение к известному IP-адресу также доступно.

Профиль Xray или sing-box должен давать доступ к указанному серверу SoftEther. Trisko направляет соединение с ним через локальный HTTP-прокси активного профиля и исключает подсеть рабочих мест из TUN. Если используется внутреннее имя вроде `softether.example.invalid`, сопоставление имени с фактическим адресом SoftEther настраивается на стороне вашего VPN-сервера. Для импортированных конфигураций VPN, где вы сами задаёте правила, требуется такая же маршрутизация. [Документация SoftEther по подключению через прокси](https://www.softether.org/4-docs/1-manual/4/4.4).
