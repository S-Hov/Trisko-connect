# Trisko connect 0.1.1

- Спокойная синяя тема и единый синий акцент вместо зелёной заливки интерфейса.
- Исходные тёмная и светлая палитры восстановлены без изменения их цветов.
- Синий векторный логотип без фона; системные значки сформированы из того же SVG.
- Панель статусов использует всю ширину для трёх оставшихся служб.
- При отсутствии VPN-профилей показано приглашение добавить ссылку или подписку. Пустая карточка «активного» сервера и ложный индикатор проверки пинга скрыты.
- В настройках ЭЦП используется та же иконка, что в боковом меню.
- README и описание GitHub представляют приложение как программу корпоративного доступа.
- Файлы, классы, пространства имён и ресурсы переименованы из Geksa в Trisko.
- Настройки и файлы ресурсов предыдущей версии читаются совместимо; существующая статистика подписок сохраняется.
