# Trisko connect 0.1.0

- Самостоятельный универсальный клиент на базе v2rayN и Geksa-A Connection.
- Новое название, значок Trisko и фирменная мятная тема.
- Несколько независимых именованных VPN-подписок с отдельным обновлением и удалением.
- Одиночные VPN-ссылки без обязательной подписки.
- Русский и английский интерфейс с выбором языка в настройках.
- Прямой запуск AnyDesk; удалены каскадные роли, zapret2, WARP и разблокировка сервисов.
- Убраны пилотная сеть VNC и предустановленные параметры сервера 1С.
- Сохранены RDP, SSH, SMB, ЭЦП/VirtualHere и VNC по адресу компьютера.
