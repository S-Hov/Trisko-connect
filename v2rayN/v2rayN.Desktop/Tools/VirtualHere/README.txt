VirtualHere Client for Windows, version 6.0.2

File: vhui64.exe
SHA-256: 85342F60273C46E84915235C79F341455EB2039EDC5901941E7FB3651B1C52F4
Official site: https://www.virtualhere.com/
Client API documentation: https://www.virtualhere.com/client_api

The executable is shipped next to Geksa-A Connection and is controlled through
VirtualHere's documented local named-pipe API (\\.\pipe\vhclient).

Geksa-A Connection starts the client with its own configuration stored under
%APPDATA%\Geksa-A Connection\VirtualHere\vhui.ini. AutoMinimize=1 keeps the
native VirtualHere window hidden during application startup.
